Recordings are saved to by default. This needs no permission. Pick another folder if you prefer.

Chrome may ask you to allow a chosen folder again in a new browser session. If you do not, recordings go to Downloads instead.

3

Transcripts (optional)

Turn the text of a call into a transcript, made on this computer. Chrome only lets an extension read files in a folder you allow, so this allows reading recordings in .

The first transcript downloads a speech model once (about 77 MB), because the model must run here to keep your recordings off other people's servers. It is kept, so nothing is downloaded again. You can skip this now and turn it on later from a recording.
